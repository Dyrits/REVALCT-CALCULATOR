# Revalct Calculator

A calculator application built with React.

## About The Project

From the original README: this is the author's first project using React, made while coding along with the Udemy course "The Complete Full-Stack JavaScript Course!", and improved a bit from the original version.

From the author's notes: a more complete calculator built from scratch with vanilla JavaScript (without `eval()`) as part of [The Odin Project](https://www.theodinproject.com/)'s curriculum can be found at [WEBDEV-TOP-RTC](https://github.com/Dyrits/WEBDEV-TOP-RTC).

## Built With

- React (Create React App)

## Getting Started

Install the dependencies with `npm install`, then start the development server with `npm start` and open http://localhost:3000.
